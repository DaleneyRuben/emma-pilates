# Follow-up — Home's referral shortcut promises classes instead of Credit

Targets: **02 (Inicio), "Sin plan activo" frame**. Send as a follow-up,
alongside checklist [30](./30-invariants-checklist.md).

---

The "Mis referidos" quick action on `02`'s no-plan frame reads **"Invita y gana
clases"**. A Referral grants the referrer **Bs 60 in Credit** once the referred
Client's first Payment is confirmed; it never grants classes
([`booking/CONTEXT.md`](../../../../booking/CONTEXT.md), *Referral*, *Credit*;
`16` and `17` already say Credit).

Change that line to **"Invita amigas y gana crédito"**, the wording [39](./39-align-booking-membership-schema.md) §4 already set. The built app shows it whenever
the Client has not invited anyone yet, in both frames; once someone signed up
with their code it reads "N amigas invitadas", as the active frame already
shows. The Evaluation shortcut likewise reads "Próxima: 2 de septiembre" when
one is booked and **"Agenda tu cita del mes"** otherwise (replacing "Agenda tu
primera cita", which is wrong for a Client who already had one in an earlier
month).

Nothing else on `02` changes.
