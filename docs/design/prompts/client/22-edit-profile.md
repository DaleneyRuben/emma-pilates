# Prompt 22 — Edit Profile

Client mobile app. Chains from Prompt 18 (Profile / Settings) — reached by tapping the "Editar" link next to the profile summary card. Returns to Profile / Settings on save.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Profile / Settings (Prompt 18), design the **Edit Profile** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** no tab bar; a back arrow in the header returns to Profile / Settings without saving.

**Layout, top to bottom:**
1. Header: back arrow, title "Editar perfil".
2. Avatar placeholder with a small "Cambiar foto" text link beneath it (uploads an image; initials-on-tint remains the fallback if none is set — same avatar treatment as the rest of the app, no photos shipped in this design bundle).
3. Field: "Nombre".
4. Field: "Correo electrónico".
5. Field: "Teléfono".
6. A "Guardar cambios" primary button (Palo de rosa fill), pinned at the bottom.

Pre-fill all fields with the client's current data. Generous whitespace, consistent with the rest of the app.
