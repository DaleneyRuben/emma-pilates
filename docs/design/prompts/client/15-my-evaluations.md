# Prompt 15 — My Evaluations

Client mobile app. Reached from Perfil — a related screen to the booking flow (Prompts 13–14) but independently prompted, since it's a list/management view rather than a continuation of booking.

---

Using the Emma Pilates Studio design system (Prompt 00), design the **My Evaluations** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present, "Perfil" active; a back arrow in the header returns to Perfil.

**Layout, top to bottom:**
1. Header: back arrow, title "Mis evaluaciones".
2. A vertical list of upcoming Evaluation cards, each showing date, time, and the Nutritionist's name, with a "Cancelar" text action.

If there are no upcoming Evaluations, show an empty state: "No tienes evaluaciones próximas." with a "Reservar evaluación" button linking to Evaluation Availability (Prompt 13).

Generous whitespace, consistent with the rest of the app.
