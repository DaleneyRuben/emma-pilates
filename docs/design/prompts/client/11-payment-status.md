# Prompt 11 — Payment Status

Client mobile app. Chains from Prompt 10 (Payment) — shown immediately after sending a transfer receipt, and reachable again later (e.g. from a notification) while the Payment is pending.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Payment (Prompt 10), design the **Payment Status** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present.

**Show two separate frames:**

**Pendiente** (immediately after submitting the receipt):
- A warning-colored status icon/illustration area.
- "Tu pago está en revisión" as the main message.
- Supporting text: "Un administrador va a confirmar tu comprobante pronto. Te avisaremos apenas esté listo."
- A single button "Volver al inicio" (secondary/outlined style — this is a waiting state, not a completed action).

**Confirmado** (once an Administrator has confirmed the transfer):
- A success-colored status icon/illustration area.
- "¡Pago confirmado!" as the main message.
- A summary card of the new Subscription: Plan name, class allowance, and the paid-through end date.
- A primary button "Ir al inicio" (Palo de rosa fill).

Generous whitespace, consistent with the rest of the app. Use the semantic Warning and Success colors from Prompt 00 to visually distinguish the two states at a glance.
