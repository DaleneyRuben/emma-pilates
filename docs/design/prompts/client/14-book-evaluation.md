# Prompt 14 — Book Evaluation

Client mobile app. Chains from Prompt 13 (Evaluation Availability) — reached by tapping a time slot.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Evaluation Availability (Prompt 13), design the **Book Evaluation** confirmation screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present; a back arrow in the header returns to Evaluation Availability.

**Layout, top to bottom:**
1. Header: back arrow, title "Confirmar evaluación".
2. A summary card: selected date, time, and the Nutritionist's name.
3. A note: "Es gratuita — no usa clases de tu plan." reinforcing that this doesn't touch the client's class allowance.
4. A reminder note: "Te avisaremos un día antes y una hora antes de tu cita."
5. A "Confirmar" primary button (Palo de rosa fill) at the bottom.

Generous whitespace, consistent with the rest of the app.
