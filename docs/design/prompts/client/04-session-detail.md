# Prompt 04 — Session Detail

Client mobile app. Chains from Prompt 03 (Browse Sessions) — reached by tapping a Session card.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Browse Sessions (Prompt 03), design the **Session Detail** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar with "Reservar" active; a back arrow in the header returns to Browse Sessions.

**Layout, top to bottom:**
1. Header: back arrow, Class Type name as the title (e.g. "Reformer Pilates").
2. Trainer name with a small avatar/photo placeholder.
3. Details row: Branch/location, date, time range, duration.
4. Capacity indicator: "X de Y cupos disponibles" with a small progress/fill indicator.
5. Short description of the Class Type (a sentence or two, e.g. "Clase de Pilates con Reformer, ideal para tonificar todo el cuerpo.").
6. Primary action area at the bottom of the screen.

**Show three separate frames for the primary action area, since it changes meaningfully by state:**
- **Cupos disponibles** — primary button "Reservar" (Palo de rosa fill).
- **Clase llena** — secondary/outlined button "Unirme a la lista de espera", with a small note below: "Clase llena. Te avisaremos si se libera un cupo."
- **Sin clases disponibles en tu plan** — "Reservar" button shown disabled/greyed, with a note below: "No te quedan clases en tu plan." and a text link "Comprar un plan" (to Plans & Payment).

Generous whitespace, consistent with the rest of the app.
