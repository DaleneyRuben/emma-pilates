# Prompt 01 — Login / Sign Up

Client mobile app. Entry screen, no previous screen to chain from — references Prompt 00 (design system) only. Prompt 02 (Home) chains from this one.

---

Using the Emma Pilates Studio design system established in Prompt 00 (Plomo cálido / Palo de rosa / Rosa empolvado / Arena cálida / Marfil palette, warm serif headings, plain sans body, soft-rounded corners, spacious layout, Palo de rosa buttons, bottom tab bar pattern), design the **Login / Sign Up** screen for the client mobile app.

This is the entry point before any authenticated content — no tab bar, no navigation chrome.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address — see exact strings below.

**Layout:** a single screen with a toggle between two modes, **Iniciar sesión** and **Registrarse**, sharing one visual frame (brand mark at top, form below, mode-switch link at the bottom).

**Brand header:** "Emma" wordmark and "Movimiento · Equilibrio · Bienestar" tagline, centered, generous top whitespace.

**Iniciar sesión mode:**
- Field: "Correo electrónico o teléfono"
- Field: "Contraseña"
- Primary button: "Iniciar sesión" (Palo de rosa fill)
- Below the button, a secondary biometric quick-login row: "Iniciar sesión con Face ID" with a Face ID icon on iOS, "Iniciar sesión con huella digital" with a fingerprint icon on Android — show both as separate platform variants of this screen
- Text link: "¿Olvidaste tu contraseña?"
- Text link: "¿No tienes una cuenta? Regístrate"

**Registrarse mode:**
- Field: "Nombre"
- Field: "Correo electrónico o teléfono"
- Field: "Contraseña"
- Collapsed/optional link "¿Tienes un código de referido?" that expands into a "Código de referido" field when tapped — not shown by default, since most sign-ups have no code
- Primary button: "Crear cuenta" (Palo de rosa fill)
- Text link: "¿Ya tienes una cuenta? Inicia sesión"

Show both mode states as separate frames in the output, and show the Log In mode in both its iOS (Face ID) and Android (Fingerprint) variants. Keep the form vertically centered with generous whitespace above and below — this is a calm, unhurried first impression of the brand, not a dense form.
