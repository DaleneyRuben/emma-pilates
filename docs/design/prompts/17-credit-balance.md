# Prompt 17 — Credit Balance

Client mobile app. Reached from Perfil, or from the credit summary row on My Referral Code (Prompt 16) — a related screen, independently prompted.

---

Using the Emma Pilates Studio design system (Prompt 00), design the **Credit Balance** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present, "Perfil" active; a back arrow in the header returns to Perfil.

**Layout, top to bottom:**
1. Header: back arrow, title "Mi crédito".
2. A large, centered balance display: "Bs [monto] disponibles".
3. Explanatory text: "Este crédito se aplica automáticamente al monto que pagues por tu próximo plan."
4. A text link "Ver mis referidos" to My Referral Code (Prompt 16).

**Show a second frame for the zero-balance state**: the balance reads "Bs 0" and below it, in place of the explanatory text, a short encouraging line — "Aún no tienes crédito. Invita a tus amigos para ganar." — with a "Ver mi código" button linking to My Referral Code.

Generous whitespace, consistent with the rest of the app.
