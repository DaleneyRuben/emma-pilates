# Prompt 09 — Plan Detail

Client mobile app. Chains from Prompt 08 (Browse Plans) — reached by tapping a Plan card. Prompt 10 (Payment) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Browse Plans (Prompt 08), design the **Plan Detail** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present; a back arrow in the header returns to Browse Plans.

**Layout, top to bottom:**
1. Header: back arrow, title matching the Plan name (e.g. "Paquete de 8 clases").
2. Plan summary: duration and class allowance restated clearly (e.g. "8 clases · Válido por 1 mes").
3. A price breakdown card:
   - "Precio del plan: Bs 300"
   - "Crédito aplicado: −Bs 50" (only shown if the client has Credit; omit this line entirely in the no-credit case)
   - A visually separated total line: "Total a pagar: Bs 250"
4. A "Continuar al pago" primary button (Palo de rosa fill), fixed at the bottom.

Show two frames: **with** Credit applied (three-line breakdown) and **without** Credit (two-line breakdown, price = total), matching the two Browse Plans states.

Generous whitespace, consistent with the rest of the app.
