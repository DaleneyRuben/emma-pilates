# Prompt A01 — Login

Assistant app. Entry screen, references Prompt 00 (design system) only. Prompt A02 (Client Search) chains from this one.

---

Using the Emma Pilates Studio design system established in Prompt 00, design the **Login** screen for the assistant app.

Staff Member accounts (Assistants included) are created by an Administrator, never self-registered — so there is **no Sign Up mode**, a single login form only.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Responsive:** this app is used on both phones and tablets at the front desk (see design system's Assistant App Responsiveness note). On tablet, keep the login form in a centered, width-constrained card rather than stretching it full-width.

This is the entry point before any authenticated content — no navigation chrome.

**Layout:**
- Brand header: "Emma" wordmark and "Movimiento · Equilibrio · Bienestar" tagline, centered, generous top whitespace.
- Field: "Correo electrónico o teléfono"
- Field: "Contraseña"
- Primary button: "Iniciar sesión" (Palo de rosa fill)
- Below the button, a secondary biometric quick-login row: "Iniciar sesión con Face ID" with a Face ID icon on iOS, "Iniciar sesión con huella digital" with a fingerprint icon on Android — show both as separate platform variants of this screen
- Text link: "¿Olvidaste tu contraseña?"
