# Prompt AW10 — Record Withdrawal

Admin desktop web. Chains from Prompt AW08 (Insumos) — reached via "Registrar retiro". A Withdrawal is logged explicitly at the moment units are taken, never inferred from a recount.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Insumos (Prompt AW08), design the **Record Withdrawal** side panel of the admin desktop web app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Registrar retiro", close icon.
2. Field: "Insumo" (dropdown, from the Branch's Supply list), showing the current stock quantity next to the selected item for reference.
3. Field: "Cantidad retirada".
4. A "Registrar" primary button (Palo de rosa fill).

This is a lightweight, fast-entry panel — a staff member takes an item off the shelf and logs it immediately, so keep the form to just these two fields plus the button, no extra steps.
