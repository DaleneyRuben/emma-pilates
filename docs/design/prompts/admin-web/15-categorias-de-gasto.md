# Prompt AW15 — Categorías de Gasto

Admin desktop web. Reached via the sidebar's "Back Office" group, or the inline "+ Nueva categoría" link on Expense Form (Prompt AW14). Same shell as Horario (Prompt AW02).

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Categorías de Gasto** page of the admin desktop web app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Back Office" expanded, "Categorías de Gasto" active.

An Expense Category is just a label (e.g. "Mantenimiento," "Reparación") — no other fields — so this doesn't need a separate form panel like the rest of Back Office.

**Layout, top to bottom:**
1. Page title "Categorías de gasto".
2. A simple list of existing categories, each row showing the name with a small delete icon (only enabled if no Expense currently references it).
3. An inline "+ Agregar categoría" row at the bottom — a text field and an "Agregar" button, adding directly to the list without a modal or panel.

Minimal, single-purpose page — no data table needed for something this simple, just a clean list.
