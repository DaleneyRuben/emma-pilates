# Prompt AW04 — Planes

Admin desktop web. Reached via the sidebar's "Catálogo" group. Same shell as Horario (Prompt AW02). Prompt AW05 (Plan Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Planes** page of the admin desktop web app — managing the Plan catalog shown to clients in the mobile app's Browse Plans screen.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Catálogo" expanded, "Planes" active.

**Layout, top to bottom:**
1. Page title "Planes" with a "+ Nuevo plan" button (Palo de rosa fill) at the top right.
2. A data table, one row per Plan: columns "Nombre" (e.g. "Paquete de 8 clases"), "Duración" (1/3/6/12 meses), "Clases incluidas", "Precio".

Clicking "+ Nuevo plan" or a row navigates to Plan Form (Prompt AW05).

Clean desktop table density per the design system's list convention.
