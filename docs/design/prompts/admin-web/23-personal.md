# Prompt AW23 — Personal

Admin desktop web. Reached via the sidebar's "Back Office" group. Same shell as Horario (Prompt AW02). Prompt AW24 (Formulario de Personal) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Personal** page of the admin desktop web app — managing Staff Member accounts (Trainer, Assistant, Administrator, Nutritionist).

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Back Office" expanded, "Personal" active.

**Layout, top to bottom:**
1. Page title "Personal" with a "+ Nuevo miembro" button (Palo de rosa fill) at the top right.
2. A filter row: a search field (placeholder "Buscar por nombre") plus a "Rol" dropdown filter (Todos / Entrenador / Asistente / Administrador / Nutricionista).
3. A data table, one row per Staff Member: columns "Nombre", "Rol" (as a compact neutral tag, not a status pill — role isn't a state), "Contacto" (correo/teléfono), "Sucursales" (a comma-separated list of assigned Branch names, or "Todas" for Administrator).

Clicking "+ Nuevo miembro" or a row navigates to Formulario de Personal (Prompt AW24).

Clean desktop table density per the design system's list convention.
