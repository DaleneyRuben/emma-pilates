# Prompt AW20 — Formulario de Sucursal

Admin desktop web. Chains from Prompt AW19 (Sucursales) — reached via "+ Nueva sucursal" or by clicking a row. Shown as a side panel over the Sucursales table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Sucursales (Prompt AW19), design the **Formulario de Sucursal** — a side panel used to create or edit a Branch.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nueva sucursal" (create) or "Editar sucursal" (edit), close icon.
2. Field: "Nombre" (e.g. "Equipetrol").
3. Field: "Dirección".
4. A "Guardar" primary button (Palo de rosa fill).

Show both **Nueva sucursal** (empty) and **Editar sucursal** (pre-filled) frames. On edit, a short read-only note below the fields states this Branch already appears in the top-bar Branch selector and in every Branch-scoped Back Office record — renaming it does not move that data.

Clean desktop density, consistent with the Plan Form panel (Prompt AW05).
