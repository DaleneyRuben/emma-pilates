# Prompt AW06 — Tipos de Clase

Admin desktop web. Reached via the sidebar's "Catálogo" group. Same shell as Horario (Prompt AW02). Prompt AW07 (Class Type Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Tipos de Clase** page of the admin desktop web app — managing the Class Type catalog (e.g. "Reformer Pilates", "Mat Pilates") that Sessions are scheduled from.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Catálogo" expanded, "Tipos de Clase" active.

**Layout, top to bottom:**
1. Page title "Tipos de clase" with a "+ Nuevo tipo de clase" button (Palo de rosa fill) at the top right.
2. A data table, one row per Class Type: columns "Nombre", "Duración" (minutes), "Capacidad" (default), "Equipo necesario".

Clicking "+ Nuevo tipo de clase" or a row navigates to Class Type Form (Prompt AW07).

Clean desktop table density per the design system's list convention.
