# Prompt AW14 — Expense Form

Admin desktop web. Chains from Prompt AW13 (Gastos) — reached via "+ Nuevo gasto" or by clicking a row. Shown as a side panel over the Gastos table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Gastos (Prompt AW13), design the **Expense Form** — a side panel used to create or edit an Expense.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nuevo gasto" (create) or "Editar gasto" (edit), close icon.
2. Field: "Categoría" (dropdown, from Expense Categories — Prompt AW15), with a small "+ Nueva categoría" link below it for adding one inline without leaving the form.
3. Field: "Monto".
4. Field: "Fecha".
5. A "Guardar" primary button (Palo de rosa fill).

Show both **Nuevo gasto** (empty) and **Editar gasto** (pre-filled) frames.
