# Prompt AW05 — Plan Form

Admin desktop web. Chains from Prompt AW04 (Planes) — reached via "+ Nuevo plan" or by clicking a row. Shown as a side panel over the Planes table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Planes (Prompt AW04), design the **Plan Form** — a side panel used to create or edit a Plan.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nuevo plan" (create) or "Editar plan" (edit), close icon.
2. Field: "Nombre" (e.g. "Paquete de 8 clases").
3. Field: "Duración" — a choice of 1, 3, 6, or 12 meses.
4. Field: "Clases incluidas" (a number — the fixed class allowance).
5. Field: "Precio".
6. A "Guardar" primary button (Palo de rosa fill).

Show both **Nuevo plan** (empty) and **Editar plan** (pre-filled) frames.

Clean desktop density, consistent with the Session Form panel (Prompt AW03).
