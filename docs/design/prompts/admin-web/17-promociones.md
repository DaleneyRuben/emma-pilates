# Prompt AW17 — Promociones

Admin desktop web. Reached via the sidebar's "Promociones" group. Same shell as Horario (Prompt AW02). Prompt AW18 (Promotion Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Promociones** page of the admin desktop web app — managing the carousel shown on the client mobile app's Home screen (Prompt 02 in the client prompt set).

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Promociones" active.

Since this is a carousel, **order matters** — this page is a deliberate exception to the usual data-table list convention.

**Layout, top to bottom:**
1. Page title "Promociones" with a "+ Nueva promoción" button (Palo de rosa fill) at the top right.
2. A vertical, drag-to-reorder list of cards — one per Promotion — each showing a small thumbnail of its image, headline, and its display date range, with a drag handle on the left edge and an edit affordance on click.

Dragging a card to a new position updates the order the carousel shows it in on the client app. Clicking "+ Nueva promoción" or a card navigates to Promotion Form (Prompt AW18).

Clean desktop density, but this list should feel tactile — the drag handles and card spacing should make reordering feel obviously possible at a glance.
