# Prompt AW07 — Class Type Form

Admin desktop web. Chains from Prompt AW06 (Tipos de Clase) — reached via "+ Nuevo tipo de clase" or by clicking a row. Shown as a side panel over the Tipos de Clase table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Tipos de Clase (Prompt AW06), design the **Class Type Form** — a side panel used to create or edit a Class Type.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nuevo tipo de clase" (create) or "Editar tipo de clase" (edit), close icon.
2. Field: "Nombre" (e.g. "Reformer Pilates").
3. Field: "Duración" (minutes).
4. Field: "Capacidad" (default capacity — individual Sessions can still override this, per the Session Form).
5. Field: "Equipo necesario" (short text).
6. A "Guardar" primary button (Palo de rosa fill).

Show both **Nuevo tipo de clase** (empty) and **Editar tipo de clase** (pre-filled) frames.

Clean desktop density, consistent with the Plan Form panel (Prompt AW05).
