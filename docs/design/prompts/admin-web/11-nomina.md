# Prompt AW11 — Nómina

Admin desktop web. Reached via the sidebar's "Back Office" group. Same shell as Horario (Prompt AW02). Prompt AW12 (Salary Payment Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Nómina** page of the admin desktop web app — Salary Payment records. Not Branch-scoped, unlike most of Back Office (a Staff Member's Branch assignments don't scope their pay records).

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Back Office" expanded, "Nómina" active.

**Layout, top to bottom:**
1. Page title "Nómina" with a "+ Registrar pago" button (Palo de rosa fill) at the top right.
2. A data table, one row per Salary Payment: columns "Empleado", "Monto", "Fecha".

Clicking "+ Registrar pago" navigates to Salary Payment Form (Prompt AW12); clicking a row opens it in edit mode.

Clean desktop table density per the design system's list convention.
