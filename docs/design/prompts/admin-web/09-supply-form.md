# Prompt AW09 — Supply Form

Admin desktop web. Chains from Prompt AW08 (Insumos) — reached via "+ Nuevo insumo" or by clicking a row. Shown as a side panel over the Insumos table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Insumos (Prompt AW08), design the **Supply Form** — a side panel used to create or edit a Supply.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nuevo insumo" (create) or "Editar insumo" (edit), close icon.
2. Field: "Nombre" (e.g. "Papel higiénico").
3. Field: "Cantidad en stock" (only editable as a starting value on create — day-to-day changes happen through Record Withdrawal, Prompt AW10, not by editing this number directly).
4. Field: "Umbral de alerta" — the quantity at or below which the low-stock badge appears in the Insumos table.
5. A "Guardar" primary button (Palo de rosa fill).

Show both **Nuevo insumo** (empty) and **Editar insumo** (pre-filled, "Cantidad en stock" shown read-only) frames.

Clean desktop density, consistent with the rest of Back Office.
