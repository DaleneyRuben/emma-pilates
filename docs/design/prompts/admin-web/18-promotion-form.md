# Prompt AW18 — Promotion Form

Admin desktop web. Chains from Prompt AW17 (Promociones) — reached via "+ Nueva promoción" or by clicking a card. Shown as a side panel over the Promociones list.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Promociones (Prompt AW17), design the **Promotion Form** — a side panel used to create or edit a Promotion.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Nueva promoción" (create) or "Editar promoción" (edit), close icon.
2. An image upload area — dashed-border tap target with a preview once an image is attached.
3. Field: "Título".
4. Field: "Descripción" (short text area).
5. Fields: "Fecha de inicio" and "Fecha de fin" (the display date range).
6. A "Guardar" primary button (Palo de rosa fill).

Show both **Nueva promoción** (empty) and **Editar promoción** (pre-filled, image already attached) frames.
