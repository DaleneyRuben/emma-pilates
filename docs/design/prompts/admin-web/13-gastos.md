# Prompt AW13 — Gastos

Admin desktop web. Reached via the sidebar's "Back Office" group. Same shell as Horario (Prompt AW02). Prompt AW14 (Expense Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Gastos** page of the admin desktop web app — Expenses for the currently-selected Branch.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Back Office" expanded, "Gastos" active.

**Layout, top to bottom:**
1. Page title "Gastos" with a "+ Nuevo gasto" button (Palo de rosa fill) at the top right.
2. A data table, one row per Expense: columns "Categoría", "Monto", "Fecha".

Clicking "+ Nuevo gasto" navigates to Expense Form (Prompt AW14); clicking a row opens it in edit mode.

Clean desktop table density per the design system's list convention.
