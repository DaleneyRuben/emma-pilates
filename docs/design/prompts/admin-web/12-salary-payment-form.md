# Prompt AW12 — Salary Payment Form

Admin desktop web. Chains from Prompt AW11 (Nómina) — reached via "+ Registrar pago" or by clicking a row. Shown as a side panel over the Nómina table.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Nómina (Prompt AW11), design the **Salary Payment Form** — a side panel used to record that a Staff Member was paid.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Layout, top to bottom:**
1. Panel header: title "Registrar pago" (create) or "Editar pago" (edit), close icon.
2. Field: "Empleado" (dropdown of Staff Members).
3. Field: "Monto".
4. Field: "Fecha".
5. A "Guardar" primary button (Palo de rosa fill).

This only records that a payment happened — amount and date — not how the amount was calculated, since that arrangement (per Session, per day, per month) happens entirely outside the system. Keep the form to just these three fields.

Show both **Registrar pago** (empty) and **Editar pago** (pre-filled) frames.
