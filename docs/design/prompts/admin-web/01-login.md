# Prompt AW01 — Login

Admin desktop web. Entry screen, references Prompt 00 (design system) only. Prompt AW02 (Horario) chains from this one.

---

Using the Emma Pilates Studio design system established in Prompt 00, design the **Login** page for the admin desktop web app.

Staff Member accounts (Administrators included) are created by an Administrator, never self-registered — so there is **no Sign Up mode**, a single login form only.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Responsive:** design a desktop frame (centered card, generous surrounding whitespace, browser chrome implied) and a narrow/mobile-browser frame (see design system's Admin Desktop Web Responsiveness note) where the same card fills the width with less side padding.

This is the entry point before any authenticated content — no sidebar, no navigation chrome.

**Layout:**
- Brand header: "Emma" wordmark and "Movimiento · Equilibrio · Bienestar" tagline, centered.
- Field: "Correo electrónico"
- Field: "Contraseña"
- Primary button: "Iniciar sesión" (Palo de rosa fill)
- Text link: "¿Olvidaste tu contraseña?"

No biometric option here — desktop browsers don't have Face ID/fingerprint the way the native mobile apps do.
