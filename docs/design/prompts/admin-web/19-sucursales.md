# Prompt AW19 — Sucursales

Admin desktop web. Reached via the sidebar's "Catálogo" group. Same shell as Horario (Prompt AW02). Prompt AW20 (Sucursal Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Sucursales** page of the admin desktop web app — managing the Branches that every other admin-web page scopes its data to via the top-bar Branch selector.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Catálogo" expanded, "Sucursales" active.

**Layout, top to bottom:**
1. Page title "Sucursales" with a "+ Nueva sucursal" button (Palo de rosa fill) at the top right.
2. A data table, one row per Branch: columns "Nombre" (e.g. "Equipetrol") and "Dirección".

Clicking "+ Nueva sucursal" or a row navigates to Sucursal Form (Prompt AW20).

There is no delete action — a Branch with any Session history is never removed, only its name/address edited. Clean desktop table density per the design system's list convention.
