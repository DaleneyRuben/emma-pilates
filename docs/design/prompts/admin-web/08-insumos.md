# Prompt AW08 — Insumos

Admin desktop web. Reached via the sidebar's "Back Office" group. Same shell as Horario (Prompt AW02). Prompt AW09 (Supply Form) and Prompt AW10 (Record Withdrawal) chain from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and the same shell as Horario (Prompt AW02), design the **Insumos** page of the admin desktop web app — Supplies for the currently-selected Branch (from the top bar Branch selector).

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Sidebar state:** "Back Office" expanded, "Insumos" active.

**Layout, top to bottom:**
1. Page title "Insumos" with two buttons at the top right: "Registrar retiro" (secondary/outlined) and "+ Nuevo insumo" (Palo de rosa fill).
2. A data table, one row per Supply: columns "Nombre", "Cantidad en stock", and a status column — a Warning-colored "Stock bajo" badge when quantity is at or below the alert threshold, otherwise blank.

Clicking "+ Nuevo insumo" navigates to Supply Form (Prompt AW09); "Registrar retiro" navigates to Record Withdrawal (Prompt AW10); clicking a row opens Supply Form in edit mode.

Clean desktop table density per the design system's list convention.
