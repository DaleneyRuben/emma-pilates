# Prompt 16 — My Referral Code

Client mobile app. Reached from Home's "Mis referidos" quick action (Prompt 02) or from Perfil. References Prompt 00 for style.

---

Using the Emma Pilates Studio design system (Prompt 00), design the **My Referral Code** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present, "Perfil" active; a back arrow in the header returns to Perfil.

**Layout, top to bottom:**
1. Header: back arrow, title "Mis referidos".
2. A prominent card showing the client's unique referral code in large type, with a "Compartir" button (Palo de rosa fill) below it that would open a native share sheet.
3. Explanatory text: "Comparte tu código. Cuando un amigo se registre y haga su primer pago, ganas crédito."
4. A small credit balance summary row — "Tu crédito: Bs [monto]" — tappable, linking to Credit Balance (Prompt 17).
5. A list of past referrals below, each showing the referred person's name (or first name) and a status badge: warning-colored "Esperando su primer pago" for a signed-up-but-not-yet-paid referral, success-colored "Crédito ganado" once their first Payment is confirmed.

If there are no referrals yet, show an empty state in place of the list: "Aún no has invitado a nadie. ¡Comparte tu código!"

Generous whitespace, consistent with the rest of the app.
