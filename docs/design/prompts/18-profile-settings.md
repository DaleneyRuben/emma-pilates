# Prompt 18 — Profile / Settings

Client mobile app. The "Perfil" tab's landing screen — the hub for everything not on the tab bar itself.

---

Using the Emma Pilates Studio design system (Prompt 00), design the **Profile / Settings** screen of the client mobile app — the landing screen for the "Perfil" tab.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar with "Perfil" active. No back arrow — this is a tab root.

**Layout, top to bottom:**
1. Profile summary card: avatar placeholder, client's name, email or phone, and a small "Editar" text link.
2. A menu list of rows (icon + label + trailing chevron), each linking further into the app:
   - "Mi plan" (→ Subscription Detail)
   - "Mis evaluaciones" (→ My Evaluations)
   - "Mis referidos" (→ My Referral Code)
   - "Mi crédito" (→ Credit Balance)
   - "Notificaciones" (→ Notifications)
3. A "Cerrar sesión" button at the bottom, styled as a muted/outlined action rather than a primary Palo de rosa button, since logging out isn't the screen's main purpose.

Generous whitespace, soft-rounded cards and list rows per the design system.
