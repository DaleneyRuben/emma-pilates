# Prompt S17 — Availability Block Form (Nutritionist)

Staff app, Nutritionist role. Chains from Prompt S16 (Mi Disponibilidad) — reached via "+ Nuevo horario" or by tapping a card.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Mi Disponibilidad (Prompt S16), design the **Availability Block Form** of the staff app, as seen by the Nutritionist.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** a back arrow in the header returns to Mi Disponibilidad.

**Layout, top to bottom:**
1. Header: back arrow, title "Nuevo horario" (create) or "Editar horario" (edit).
2. Field: "Día" (day of week).
3. Field: "Hora de inicio" and "Hora de fin".
4. A short note below the fields: "El sistema generará turnos de evaluación individuales dentro de este horario." — the system auto-generates fixed-length, individually bookable Evaluation slots from this range, the Nutritionist isn't setting slots one by one.
5. A "Guardar" primary button (Palo de rosa fill).

Show both **Nuevo horario** (empty) and **Editar horario** (pre-filled, with a secondary "Eliminar horario" text link in the Error semantic color) frames.

Generous whitespace, consistent with the rest of the app.
