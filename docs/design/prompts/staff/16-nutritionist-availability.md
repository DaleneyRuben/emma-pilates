# Prompt S16 — Mi Disponibilidad (Nutritionist)

Staff app, Nutritionist role. Reached from Mi Agenda's header action (Prompt S15). Prompt S17 (Availability Block Form) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Mi Agenda (Prompt S15), design the **Mi Disponibilidad** screen of the staff app, as seen by the Nutritionist — managing the open time ranges (Availability Blocks) that clients book Evaluation slots from.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** a back arrow in the header returns to Mi Agenda.

**Layout, top to bottom:**
1. Header: back arrow, title "Mi disponibilidad", with a "+ Nuevo horario" button (Palo de rosa fill) at the top right.
2. A vertical list of Availability Block cards, each showing a day and time range (e.g. "Martes, 9:00 – 13:00").

Tapping "+ Nuevo horario" or a card navigates to Availability Block Form (Prompt S17).

If there are no Availability Blocks published yet, show an empty state: "Aún no publicaste horarios de disponibilidad." with the "+ Nuevo horario" button emphasized as the next step.

Generous whitespace, soft-rounded cards per the design system.
