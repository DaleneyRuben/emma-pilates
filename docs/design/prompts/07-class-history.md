# Prompt 07 — Class History

Client mobile app. Reached from My Bookings (Prompt 05) via the "Ver historial" link — a related screen, independently prompted since it's a read-only report rather than a continuation of the booking flow.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with My Bookings (Prompt 05), design the **Class History** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar with "Mis Reservas" active; a back arrow in the header returns to My Bookings.

**Layout, top to bottom:**
1. Header: back arrow, title "Historial de clases".
2. A list of past attended classes — Bookings whose Attendance was recorded as attended — grouped by month (e.g. "Agosto 2026", "Julio 2026" as section headers), each entry showing Class Type name, Trainer name, Branch, and date. Purely informational — no actions, no status badges, since this is a completed record.

If there's no history yet, show an empty state: "Aún no tienes clases en tu historial." with a short supporting line, no call-to-action needed.

Generous whitespace, consistent with the rest of the app. This screen reads as calmer and more understated than the active-booking screens — it's a passive record, not something the client is expected to act on.
