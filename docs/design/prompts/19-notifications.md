# Prompt 19 — Notifications

Client mobile app. Chains from Prompt 18 (Profile / Settings) — reached by tapping "Notificaciones". This is the final screen in the client mobile app chain.

---

Using the Emma Pilates Studio design system (Prompt 00) and consistent with Profile / Settings (Prompt 18), design the **Notifications** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present, "Perfil" active; a back arrow in the header returns to Profile / Settings.

**Layout, top to bottom:**
1. Header: back arrow, title "Notificaciones".
2. A vertical list of notification entries, each with a small icon, a message, and a relative timestamp (e.g. "Hace 2 horas"). Unread entries carry a subtle background tint and a small dot indicator; read entries are plain.

**Include a representative mix of the notification types this app sends**, so the list reads as real content:
- "Tu clase de Reformer Pilates fue cancelada. Tu clase fue reembolsada a tu plan." (Session cancelled by an Administrator)
- "¡Tienes un cupo! Te promovimos de la lista de espera para tu clase de Mat Pilates." (Waitlist promotion)
- "Tu pago fue confirmado. ¡Ya puedes reservar clases!" (Payment confirmed)
- "Tu plan vence en 3 días." (Renewal reminder)
- "Recordatorio: tu evaluación nutricional es mañana." (Evaluation reminder, 1 day before)
- "Recordatorio: tu evaluación nutricional es en 1 hora." (Evaluation reminder, 1 hour before)

If there are no notifications, show an empty state: "No tienes notificaciones." with a simple supporting line.

Generous whitespace, consistent with the rest of the app.
