# Prompt 08 — Browse Plans

Client mobile app. Reached from Home's "Comprar un plan" CTA (Prompt 02) or from Perfil, when the client has no active Subscription. References Prompt 00 for style. Prompt 09 (Plan Detail) chains from this one.

---

Using the Emma Pilates Studio design system (Prompt 00), design the **Browse Plans** screen of the client mobile app.

**Language:** all visible copy is neutral Spanish (Bolivia), informal "tú" address.

**Navigation chrome:** bottom tab bar present (no tab is the natural match — treat as reached from Perfil, with "Perfil" active); a back arrow in the header returns to where the client came from.

**Layout, top to bottom:**
1. Header: back arrow, title "Elige tu plan".
2. If the client has an available Credit balance (from Referrals), a banner near the top: "Tienes Bs [monto] de crédito disponible — se aplicará a tu próxima compra."
3. A vertical list of Plan cards, one per Plan, each showing: Plan name (e.g. "Paquete de 8 clases"), duration (e.g. "Válido por 1 mes"), class allowance (e.g. "8 clases"), and price. If Credit applies, show the original price struck through next to the discounted final price.

Show two frames: one **without** a Credit balance (plain prices), and one **with** a Credit balance (banner shown, discounted prices shown), so both states are covered.

Tapping a Plan card navigates to Plan Detail (Prompt 09).

Generous whitespace, soft-rounded cards per the design system.
